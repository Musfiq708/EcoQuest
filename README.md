# EcoQuest 🌿

An interactive web for those who want to adventure . EcoQuest helps them select the perfact trip to enjoy . We have expert guides who will help you enjoy the best moments of your trip.

## Live Link
[EcoQuest Live] [https://ecoquest-632c2.web.app/]

## Purpose
To create a Website for traveling people , help them have the best experiece

## Key Features
- **Renponsive UI**: Daily and weekly eco-friendly tasks
- **Login&Registration**: Visual tracking of environmental impact
- **SinglePage**: Curated articles and videos on sustainability
- **GoogleAuthentication**: Badges and rewards for completed actions
- **ForgetPassword**: Share experiences and tips with other users

## Technology 
- **Frontend**: React.js, Tailwind CSS , Daisy UI
- **Authentication**: Firebase Auth
